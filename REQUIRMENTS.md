# Project Requirements

## 1. Application Requirements

- User should be able to open the chat application.
- User should be able to send a message.
- Application should generate/display a response.
- Chat data should be stored in a database.

## 2. Development Requirements

- Frontend
- Backend
- Database
- Git
- GitHub

## 3. DevOps Requirements

- Docker
- CI/CD
- AWS
- Terraform
- CloudWatch

## 4. Deployment Requirements

- Application should run inside Docker.
- Application should be deployed on AWS.
- Deployment should be automated using CI/CD.

## 5. Monitoring Requirements

- Application logs should be available.
- Basic AWS monitoring should be configured.
